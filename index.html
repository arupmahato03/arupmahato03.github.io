What I built

I decomposed the codebase into 10+ Spring Boot microservices and built 100+ REST endpoints behind JWT authentication and role-based authorization with Spring Security. On the payment path: idempotency keys and webhook reconciliation. On the data path: profiled Hibernate/JPA queries, resolved N+1s, added composite indexes to the MySQL schema, and put Redis in front of hot reads. I also built the aggregation services and reporting APIs behind the internal analytics dashboards.

Outcome

Services deploy independently instead of as one unit. No unauthorized-access defects across the services I secured, no duplicate charges or payment mismatches across 100+ monthly transactions, and a measurable drop in average API response time after the query and caching work. The Wix plugin and CRM integration layers standardized third-party sync and cut manual reconciliation.

  • Designed and delivered 10+ Spring Boot microservices supporting high-traffic production applications, decomposing a monolithic codebase to enable independent, faster deployments.
  • Built and secured 100+ REST endpoints with JWT authentication and role-based authorization using Spring Security, eliminating unauthorized-access defects across all services.
  • Integrated payment gateway flows handling 100+ monthly transactions, implementing idempotency keys and webhook reconciliation to prevent duplicate charges and payment mismatches.
  • Optimized Hibernate/JPA queries and MySQL schemas by resolving N+1 query issues, adding composite indexes, and introducing Redis caching for frequently accessed data, measurably reducing average API response time.
  • Developed backend services for an analytics platform, aggregating event data and exposing reporting APIs consumed by internal dashboards for business decision-making.
  • Delivered Wix plugin services and CRM integration layers, standardizing third-party data sync and reducing manual reconciliation effort.

About

I like the part of a product that has to be correct.

Not the part that has to look good — the part where a payment either goes through exactly once or it doesn't, where two people bidding on the same listing at the same second both get an honest answer, where a query either returns fast or holds up every request queued behind it.

I've spent three years there: Java and Spring Boot, MySQL and Redis, REST APIs designed for the person who has to call them at 2am. Most of that work has been carving monoliths into services and making the seams — auth, payments, third-party sync — hold.

Right now I'm going deeper on distributed systems and cloud infrastructure. Based in Pune, open to backend engineering roles.
